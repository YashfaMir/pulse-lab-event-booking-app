# PULSE LAB — Music & Events Booking App

## Project Overview
PULSE LAB is a mobile app UI/UX design concept that helps users discover music events, explore concerts, and book tickets through a simple and engaging experience.

## Project Goals
- Make discovering music events easier.
- Provide a smooth ticket-booking experience.
- Create a modern and visually engaging mobile interface.

## Tools Used

- UI/UX Design
- Wireframing & Prototyping
